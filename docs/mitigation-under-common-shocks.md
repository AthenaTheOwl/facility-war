# Compare mitigation on a shared shock draw

Method update: October 18, 2026.

The simulator ranks dual sourcing, buffers and redesign by reduced outage weeks. Until October 20, 2026 those reductions were fixed rules in `_rank_mitigations`: 0.45 of the most-exposed BOM item's expected red weeks for dual sourcing, that same figure capped at 4 weeks for a buffer, and 0.30 of it for redesign. The simulator now re-simulates each mitigation as a graph or stock change on the baseline's shock draws. A mitigation ranking is conditional on the graph, scenario and response assumptions. Two alternatives that depend on the same upstream substrate can fail together; adding an alternative edge alone does not establish independent supply.

What is now implemented: each mitigation is a graph or stock change, and the baseline and each mitigation run on identical shock draws. A second source has a qualification delay and inherits the original component's other inputs, so a shared upstream node can still take both down (`tests/test_mitigation_resimulation.py` checks that case). Each candidate reports outage-week reduction, the week it becomes effective, residual expected red weeks and residual outage probability. A fix that begins after the shock gets no protection credit for the weeks before it starts. Mitigation cost is still not modeled.

Keep the existing historical calibration gate and fixture traceability. A fit on one disruption does not establish coverage of every new scenario. Preserve the original run and state which changed assumptions require a rerun; the superseded `run.json` and report stay in git history. This note does not claim a new backtest. The published ranking changed: the top move is now a second source for the Taiwan packaging supplier, not the substrate supplier, which saves nothing because ABF substrate already has a qualified alternate.
